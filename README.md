# Timestamp Microservice

A lightweight REST API for converting between Unix timestamps and UTC date strings. Built with Node.js and Express, this service accepts either a human-readable date or a Unix timestamp and returns a consistent JSON response that is easy to consume from web applications, scripts, and automated tests.

## Overview

The Timestamp Microservice provides a simple endpoint for converting dates into two commonly used formats:

- **Unix timestamp** — the number of milliseconds since January 1, 1970, UTC
- **UTC date string** — a standardized date representation generated by JavaScript's `Date` API

When no date is supplied, the API returns the current time.

## Features

- Convert standard date strings, including `2015-12-15` and `December 15, 2015`
- Convert Unix timestamps expressed in seconds or milliseconds
- Return the current timestamp when no date is provided
- Return predictable JSON responses
- Provide an `Invalid Date` response for unsupported or invalid input
- Include CORS support for browser-based clients
- Remain small, fast, and easy to deploy

## API Reference

### Base URL

```text
https://timestamp-microservice-8rg2.onrender.com
```

### Endpoint

```http
GET /api/:date?
```

The `date` parameter is optional. If it is omitted, the service returns the current timestamp.

### Supported Input Formats

#### Date string

```text
/api/2015-12-15
/api/December%2015,%202015
```

#### Unix timestamp in milliseconds

```text
/api/1451001600000
```

#### Unix timestamp in seconds

```text
/api/1451001600
```

Numeric values are interpreted as Unix timestamps. Ten-digit values are treated as seconds, while thirteen-digit values are treated as milliseconds.

## Response Format

### Current Timestamp

```json
{
  "unix": 1730000000000,
  "utc": "Mon, 28 Oct 2024 00:00:00 GMT"
}
```

### Date Conversion

```json
{
  "unix": 1451001600000,
  "utc": "Fri, 25 Dec 2015 00:00:00 GMT"
}
```

### Invalid Input

```json
{
  "error": "Invalid Date"
}
```

## Getting Started

### Prerequisites

Make sure the following are installed on your system:

- [Node.js](https://nodejs.org/) — a current LTS version is recommended
- npm — included with Node.js

3. Start the server:


## Implementation Notes

- Date strings are parsed using JavaScript's native `Date` constructor.
- Numeric input is interpreted as a Unix timestamp.
- Ten-digit numeric values represent seconds.
- Thirteen-digit numeric values represent milliseconds.
- Returned UTC values use the standard GMT string format produced by `Date.prototype.toUTCString()`.
- Invalid dates return a JSON object containing an `error` property.
